# 単音→和音のお手本（2026-11-03）

## 操作と仕様

- 音符を選択した後のメニューに「この音を鳴らす」を追加。「和音を鳴らす」の左隣に置く。選んだパートの音符1音だけを、音色・音量・移調を引き継いで1秒鳴らす。音符を選んだ瞬間の自動発音は追加せず、ボタンで再生する方式を採用。
- 同メニューと和音練習の両方に、「お手本（1秒）」「お手本（3秒）」を横並びに置く。低音から1パートずつ順に鳴らし、次の音の開始までに前の音の余韻も消す。最後に全パートを同時に鳴らす。
- 単音の長さは1秒／3秒。全体10秒の条件は撤廃。6パートの3秒版は、単音18秒＋最後の和音3秒で21秒。
- 最後の和音は暫定で3秒。明示指定されていない持続時間として、実装時にこの初期値を採用した。
- 選択メニューの「和音を鳴らす」は全パートを同時に3秒鳴らす。単音を順番に聴く場合は「お手本」を使う。
- 和音練習の「合わせる」は「和音を鳴らす」に改名。自分以外のパートを30秒まで伸ばし、マイクを使う従来機能は維持。ボタンの説明と読み上げ名に「自分以外」を残す。
- 選択メニューの試聴・お手本は押し直すと前の音を止めて鳴らし直す。和音練習内は従来どおり同じボタンをもう一度押すと停止し、別のお手本や前後の和音へ移ると切り替える。
- 通常再生の音の余韻は変更しない。厳密な終了境界を使うのは新しい試聴・お手本のみ。
