# アカペラ練習帳

アカペラサークルの**個人の音取り**のためのWebアプリです。MIDIファイルを開くと、パートごとの音程バーが流れ、マイクで歌った声の高さが線で重なります。

**公開URL：https://daddyboubakiki-stack.github.io/Carapella/**

- 1つのHTMLファイル（`index.html`）だけで動きます。外部ライブラリなし（フォントだけGoogle Fonts）
- 練習そのものにサーバーは使いません。MIDIはLINEなどで受け取り、スマホに保存してから開きます
- 曲専用リンク（準備中）：MIDIをリンク1つで渡せるようにするため、Cloudflare Workers ＋ D1 の小さなAPI（`worker/`）を使います。設定が済むまで、この機能は画面に出ません
- 対象：iPhone（Safari）・Android（Chrome）・パソコンのブラウザ

## できること

- パートを選んで、音程バーに合わせて歌う（目標の音・自分の声・ずれをセント単位で表示）
- 練習の段階：①一緒に → ②自分のガイドを小さく → ③自分のガイドなし → ④ひとりで
- 先頭／末尾、10秒戻し／送り、再生／一時停止。SVGアイコンの操作を2段に配置
- 全曲ループと区間リピート（小節で指定、回ごとの一致率を表示）
- 「自分だけ」で自分のパートだけを聴くON/OFF。再生中にも切り替えられ、譜面や練習段階はそのまま
- イヤホンなどの長い説明は丸い「？」から開く
- 画面を切り替えても聴く（試作。Android の Pixel 8・Chrome で基本の動きを確認、iPhone は未確認）：マイクと録音を使っていない時は、再生中に別アプリ・ホーム画面・画面ロックへ移っても、同じ設定（自分だけ・段階・音量・音色・テンポ・キー・ループ）で音が続く。端末の中で音声ファイルを作って引き継ぎ、戻るとその位置から続ける。ロック画面で再生・一時停止・10秒送り／戻し。区間・しおりのループ中に画面を離れると、初めの設定ではループを止めて曲の終わりまで流す（範囲は残る。「練習の設定」で、画面を離れても区間を繰り返すようにも変えられる）
- しおり：止めている時に音符を長押しすると、その音の長さで区間ができる（なぞると表示の移動）。音符をタップすると「和音を鳴らす／和音練習／ここから／ここまで」。何個でも作れ、再生バーの下にも表示。曲ごとに端末に記憶
- 音符を選んで「この音を鳴らす」で単音、「和音を鳴らす」で全パートの和音を試聴。「お手本（1秒）／お手本（3秒）」は低い音から重ねずに1音ずつ鳴らし、最後に全体の和音を3秒鳴らす
- 和音練習（一人用）：同じ2種類のお手本と、「和音を鳴らす」（旧「合わせる」＝自分以外のパートを鳴らし、自分の声を線で見る）。前後の和音へ移れる。目標は平均律
- パートごとの音量（最大200%）・音色（やわらか／はっきり／声（アー）／オルガン）・バーの色（初期はパート順に赤・橙・青・緑・紫、6つ目から灰色）。色と音色は曲ごとに端末に記憶
- カラオケ形式（.kar）の歌詞の表示
- 再生前のカウント（1小節）。③④ではカウント中に自分の最初の音を鳴らす
- テンポ（50〜125%）・キー（±12半音）の変更
- 録音して、ガイドと当時の音程の線と一緒に聴き返す・保存する
- 曲専用リンク（準備中）：開いたMIDIを「共有リンク」でリンクにし、LINEで送れる。リンクを知っている人は誰でも開ける（ログイン・合言葉なし）。作った端末から「共有をやめる」ができる。曲名とMIDIのほかは何も保存しない（IPアドレスも残さない）

## 使い方（開き方）

マイクを使うので、**https のWebページとして開く必要があります**。

- パソコンで試す：`index.html` をブラウザで開けば、マイク以外は動きます。マイクも試すなら `npx serve .` などで `http://localhost` から開きます
- スマホで使う：上の公開URLを開きます（GitHub Pages で公開。リポジトリにpushすると1分ほどで更新）
- Claudeのアーティファクトの中ではマイクが使えません（アーティファクトの仕組みでマイクが拒否されるため）

### 公開後の更新

通常の機能追加は既存URLを更新する。開いているタブのコードを自動で読み直す仕組みはなく、利用者は練習を終えてから再読み込みすると新版になる。録音はページ内のメモリにあるため、残したいテイクは再読み込み前に保存する。今回の更新は単一HTMLの置き換えで、共有APIやデータベースの変更はなく、メンテナンス画面は設けない。
